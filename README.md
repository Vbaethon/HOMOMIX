## 适用于mihomo - MetacubeX面板的Icon

# 使用前：

        需要了解编写规则配置(*.ymal)

        需要了解使用mihomo - MetacubeX面板
        

# 使用指南：

#### 1、Icons的命名本质上不和你的策略组相关联。

2、建议同步到本地，便于阅读

3、Icons地址请使用raw地址

        例如：https://raw.githubusercontent.com/Vbaethon/HOMOMIX/main/Icon/Color/China.png

#### 4、面板可以调节尺寸与距离

# Icon版本：

        等高版本（默认设置, “Color/”）
        放大版本（“Color/Large”）
        FDS版本（未完成，“Color/FDS”）

等高版实际为 300×300：图案缩至180×180并居中留白；放大版 Large 实际为360×360：同一圆形图案接近满画布。因此相同面板显示尺寸下，Large 图案更大。FDS 保留未完成状态（现有两图125×90）。

## 本轮全套校准

全套固定圆形背景，主体独立校准视觉大小与留白，并按实际36px跨类别同排检查。原创改用集中饱满图形，官方标识保留原形；重复兼容链接不再双重展示。

[完整设计及重建说明](Sources/current/README.md) · [逐项检查表](Sources/current/plan.json) · [全套实际总览](Sources/current/qa/final/full-overview.png)

长字标如 Disney Channel 与细线 Olympic 标识保留官方比例，不硬加粗或拉伸；未完全确认的9项来源限制详见 [官方审计](Sources/current/README.md#source-provenance)。
